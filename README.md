# 📊 Colorful Statistical Histogram

A colorful and informative histogram created using Python. This project visualizes normally distributed data using 10 different colored bins and adds statistical information such as the mean, median, frequency values, and a smooth normal distribution curve.

## ✨ Features

- 📊 Histogram with 10 bins
- 🌈 Different colors for each bin
- 🔢 Frequency values displayed above each bar
- 📍 Mean value line
- 📌 Median value line
- 📈 Smooth normal distribution curve
- 🎨 Clean and informative visualization
- 🔁 Reproducible results using a fixed random seed

## 🛠️ Technologies Used

- Python
- NumPy
- Matplotlib
- SciPy
